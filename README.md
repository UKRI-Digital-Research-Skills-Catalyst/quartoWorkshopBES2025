These are the training materials for the workshop "Reproducible and Automated Reporting with Quarto," developed by the UKRI Digital Research Skills Catalyst for the British Ecological Society (BES) 2025 meeting.

This tutorial introduces researchers to Quarto, a modern open-source scientific publishing system designed for creating dynamic, reproducible documents. The materials guide users away from error-prone manual write-up workflows and toward a unified system where text and code live together.
